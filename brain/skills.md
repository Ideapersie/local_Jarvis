# Skills

The narrative half of the `Skill` table. The table holds a 1-5 confidence and a
target; this file holds what those numbers actually mean — what "good at
Kubernetes" looks like for me specifically, and what the gap to target is.

Add an entry when a skill first gets a row in the table. Update it when the
confidence number moves, and say what moved it.

## Entries

_Empty. Nothing here is inferred from the CV or the course — entries land when
you set a confidence, or when an interview reveals where a skill actually sits._
