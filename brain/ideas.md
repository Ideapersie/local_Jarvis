# Ideas

Startup and project ideas, with agent feedback appended under each rather than
replacing what you wrote. Your original framing stays intact — that is the point
of appending.

## Format

```
## <Name> — YYYY-MM-DD
<your description>

### Feedback — YYYY-MM-DD
<agent's response: what is strong, what is unproven, what would test it cheaply>
```
