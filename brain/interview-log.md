# Interview log

One entry per round. What was asked, what went well, what went badly, what you
would do differently. Written from your debrief after the interview — never
predicted beforehand.

This is the file that makes patterns visible: three rounds all going sideways on
the same class of question is a signal no single debrief shows.

## Format

```
## <Company> — <Role> — <stage> — YYYY-MM-DD
**Asked:** ...
**Went well:** ...
**Went badly:** ...
**Do differently:** ...
```
